# API testing with pytest
## Project overview
It`s gonna be small project, with simple API client(using reqres), and setted up CI and automatic tests with pytest. 

Tech Stack
- Python
- Pytest
- Requests
- Faker
- Allure

### Launch
1. Setup virtual environment with packages in requirements.txt
2. Proceed to root folder
3. Run "python -m pytest conftest.py"
